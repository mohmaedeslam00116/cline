# Persona Studio

MODE: Operate. A professional developer repeatedly creates and maintains Specialist Personas in English, while existing localization infrastructure remains intact. The job is to understand identity, permissions, and prompt behavior at a glance, then save a valid workspace or global `.agent.md` artifact without losing context.

THESIS: Persona Studio is an agent calibration bench, not a settings dashboard. It refuses a stack of generic cards; the library, live chassis signal, capability envelope, and prompt are one continuous instrument for preparing a deployable persona.

OWN-WORLD: Inherit LENS Workstation’s dark theme tokens, lens/aperture geometry, Inter interface type, Geist Mono telemetry, cyan/violet activity signals, amber checkpoints, and restrained rose/emerald feedback. Quiet native controls surround one precise holographic calibration bay; no decorative gradients, glass panels, or unrelated neon ornaments.

STORY: The developer finds or duplicates a persona, confirms how it looks in all five operational states, limits its tools, authors its system prompt, chooses workspace or global scope, and saves. Built-ins remain immutable; custom personas are editable and deletable with confirmation.

FIRST VIEWPORT: Below the existing title bar, a narrow searchable library occupies the left edge. The right surface begins with identity fields beside a large avatar calibration bay showing the active chassis and five state samples. Capability controls and the Markdown editor follow in the same scroll surface. Scope, validation state, and the primary Save persona action remain visible in a restrained sticky command strip.

FORM: Dual-pane calibration bench, ranked first of the three approved implementation approaches because it preserves the existing navigation and persistence seams while separating focused components. Direct issue specification key: `direct-issue-66`; no concept seed or visual comp is used because the user selected code-first and the ticket fixes the dual-pane structure.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

CONSTRAINTS: Preserve zero-trust and Phase 1 least privilege. Use the existing persona parser, sidecar storage APIs, SVG chassis, theme primitives, and Bun toolchain. Keep keyboard access, visible focus, reduced motion, responsive operation, and exact workspace/global scope semantics. Do not add Monaco, raster avatars, squad presets, persona execution, or fabricated claims.
